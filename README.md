# NotebookLM 溫習提示詞｜香港老師版

香港中學老師用的 NotebookLM 溫習提示詞靜態網頁。八條指令改編自公開的學習提示詞，供課後輔導、考試前溫習，或派給學生自行使用。本頁並非 Google 或原文作者的官方產品。

## 本地開啟

用瀏覽器直接打開 `index.html`，或在此資料夾啟動靜態伺服器：

```bash
python3 -m http.server 8080
```

然後開啟 <http://localhost:8080>。

## GitHub Pages

網站是純靜態檔案（`index.html`、`styles.css`、`script.js`），可以從 `main` 分支的根目錄發佈。Pages 的開啟與網域由人手處理，此存放庫沒有部署設定。
